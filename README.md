Aplikasi Android untuk optimasi performa dan FPS game dengan memanfaatkan akses API **Shizuku** tanpa perlu melakukan *root* penuh pada perangkat.

---

## ✨ Fitur Utama

- **Integrasi Shizuku Native:** Menjalankan perintah tingkat sistem dengan izin terbatas tanpa butuh *root*.
- **120Hz Refresh Rate Force:** Mengunci/memaksa kecepatan *refresh rate* ke tingkat maksimal.
- **Anti-Aliasing (4x MSAA):** Mengaktifkan opsi pembacaan grafik lebih mulus via shell command.
- **Game Turbo Mode (v2.0):** Mengalokasikan CPU ke governor *performance* maksimum.
- **Haptic Feedback:** Efek respon getar saat menekan tombol toggle.

---

## 📥 Cara Unduh & Instalasi Application

1. **Unduh APK:**
   - Pilih dan klik tombol **Download Release** di atas sesuai versi yang diinginkan.
   - Unduh file `.apk` dari bagian *Assets*.

2. **Prasyarat (Shizuku):**
   - Pastikan aplikasi **Shizuku** sudah terinstal di HP kamu dan layanannya sudah berjalan (via Wireless Debugging / ADB PC).

3. **Install & Jalankan:**
   - Install file `.apk` pada perangkat Android.
   - Buka aplikasi **Boost-Fps-App** dan berikan izin (*grant permission*) Shizuku saat diminta.
